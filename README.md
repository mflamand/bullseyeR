# Bullseye

Site-level differential editing analysis with multifactor models,
custom contrasts, parallel fitting, and model diagnostics.

## Installation

Install the development version from GitHub:

```r
install.packages("remotes")
remotes::install_github("mflamand/bullseyeR")
```

Load the package:

```r
library(bullseyeR)
```

For beta-binomial models, also install the optional dependency:

```r
install.packages("aod")
```
